# Ascend Academy Gear

Plataforma de educación y equipamiento deportivo de alto rendimiento.

## Instalación y Ejecución

Sigue estos pasos para ejecutar el proyecto localmente:

1.  **Instalar dependencias**
    ```sh
    npm install
    ```

2.  **Iniciar servidor de desarrollo**
    ```sh
    npm run dev
    ```

## Tecnologías

- Vite
- TypeScript
- React
- shadcn-ui
- Tailwind CSS
